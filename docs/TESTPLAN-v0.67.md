# v0.67.0 live-test plan: the look (themes, presets, chat cards, condition monitor, portraits by name)

Two tabs: **GM** (GM AI) and **PL** (ZZ Testplayer). Drive the UI with JavaScript in the page and read the DOM and computed styles; prefer `getComputedStyle(...)` and `classList` checks over screenshots, but take the screenshots marked **[SHOT]**: those go to the user. After a setting change, a click or an update, wait about 500 ms before reading. Every test document is named "ZZ …". No Foundry restart is needed (no new document types); a browser reload (F5) is enough after updating the system.

Each check: **steps** → *expected*. Write down anything that differs, plus the console errors seen during the check.

## How to drive it

- Look settings (client scope, so each tab has its own): `lookTheme` (`street` | `corp` | `contrast`), `lookPreset` (`cyan` | `green` | `magenta` | `amber`), `windowOpacity` (50–100, step 5), `textScale` (90–130, step 5), `reducedMotion` (bool); the older `diceColours` (`default` | `colourblind` | `contrast`). Set with `await game.settings.set('sr2e', key, value)`: the setting's onChange calls `applyLook()`, no reload. `game.sr2e.api.applyLook()` re-applies by hand.
- World settings (GM): `portraitFolder` (string, e.g. `zz-avatars` (the live run used `systems/zz-avatars`, written through the desktop link)), `portraitTokens` (bool, default true).
- Body state: `document.body.classList` holds `sr2e-theme-<id>`, `sr2e-preset-<id>`, and `sr2e-reduced-motion` / `sr2e-see-through` when on; `document.body.style` holds `--sr2e-window-alpha` and `--sr2e-text-scale`. The palette is a `<style id="sr2e-palette">` in `<head>`. Read a palette colour with `getComputedStyle(document.body).getPropertyValue('--sr2e-accent').trim()`.
- Windows: `const apps = () => [...foundry.applications.instances.values()].map(a => ({ id: a.id, name: a.constructor.name, look: a.element?.classList.contains('sr2e-look'), theme: [...(a.element?.classList ?? [])].filter(c => c.startsWith('theme-')) }));`. An SR2e window has `sr2e-look themed theme-dark|theme-light`.
- Reference colours (computed `background-color` of `.application.sr2e-look`, solid): Street / cyan `rgb(27, 31, 37)`; Corp `rgb(214, 219, 225)`; High contrast `rgb(10, 12, 15)`. Title bar: Street and Corp `rgb(35, 41, 49)`, High contrast `rgb(0, 0, 0)`. Accent (`--sr2e-accent`): Street cyan `#4fd1d9`, green `#5fd68f`, magenta `#ec6fc5`, amber `#f0b35a`; Corp cyan `#085a63`; High contrast cyan `#6ff0f7`. Area colours on Street (`--sr2e-combat` etc.): combat `#d9604c`, magic `#a98ae8`, matrix `#4cc98e` (becomes `#4fd1d9` on the green preset), rigging `#e8964a`, street `#e0bd55`, health `#3fbfb2`.
- Chat cards: `const li = (m) => document.querySelector(`#chat [data-message-id="${m.id}"]`) ?? document.querySelector(`[data-message-id="${m.id}"]`);`. A decorated card is `li.chat-message.sr2e-card.sr2e-area-<combat|magic|matrix|rigging|street|health|neutral>`; inside `.message-content`: `.sr2e-roll > h3[data-kind]`, `.sr2e-count > b` (the number), `details.sr2e-fold` (summary has the TN line), `.sr2e-die.hit` / `.miss` / `.one`, `.sr2e-banner` (now after `.sr2e-roll`), `button[data-sr2e-action="karmaReroll"].sr2e-ghost`. Kind words: attack "Attack", defend "Defense", soak "Resist", spell "Spell", plain "Test", heal "Healing", medic "First aid", system "Matrix", drive "Driving", bypass "Security", notice "Perception".
- Rolls: `await game.sr2e.api.rollTest('6 tn 5', actor)` (a plain test, quick); `game.sr2e.runSheetAction(actor, 'quickAttack')` / `'quickCast'`; `game.sr2e.api.defendNewest(actor)`. "Change target number…" is on the card's right-click menu (GM only): dispatch `contextmenu` on the card `li` and click the menu entry with that text, or right-click with the mouse.
- Condition monitor (character, NPC, spirit sheets): `.sr2e-cm` holding `.sr2e-cm-track.sr2e-cm-physical`, `.sr2e-cm-track.sr2e-cm-overflow` (with `idle` while greyed), `.sr2e-cm-track.sr2e-cm-stun`. Groups are `.sr2e-cm-group` (label in `> i`, boxes `a.sr2e-box[data-action="setMonitor"][data-track][data-value]`), dividers `.sr2e-cm-div`, the reached group has `now`. Overflow boxes are `a.sr2e-box.sr2e-of`, the last one also `dead`. Matrix tracks: `.sr2e-cm-matrix` (`data-action="setMatrixMonitor"`). Small read-only monitor: `.sr2e-cm-mini` with `.sr2e-cm-bar.sr2e-cm-physical|stun|overflow`, segments `.sr2e-cm-seg > span > s(.filled)`.
- Sheets: `const sh = (a) => a.sheet; await a.sheet.render(true); const E = () => a.sheet.element;`. Tabs: `[data-action="tab"][data-tab="matrix"]` or the sheet's own tab links (`.sr2e-tabs .item[data-tab="…"]`).
- GM panel: `const gp = game.sr2e.api.gmPanel(); const G = () => gp.element;`, tabs `[data-action="gmTab"][data-tab="party"|"npcs"|"combat"|"scene"|"setup"]`.
- Other SR2e windows: `game.sr2e.api.openHelp()`, `game.sr2e.npcGenerator()`, `game.sr2e.api.creationWizard(actor)`, `game.sr2e.api.spendKarma(actor)`, the Add window from a sheet's `a.sr2e-add`, settings menus: `new (game.settings.menus.get('sr2e.houseRulesMenu').type)().render(true)` (also `sr2e.rollPrivacyMenu`, `sr2e.skillWebMenu`; their ids are `sr2e-house-rules`, `sr2e-roll-privacy`, `sr2e-skill-web`).
- Foundry's own colour scheme: `game.settings.get('core', 'uiConfig').colorScheme` (`{applications, interface}`, values `dark` | `light` | `''`). Change it with `game.settings.set('core', 'uiConfig', foundry.utils.mergeObject(foundry.utils.deepClone(cur), {colorScheme: {interface: 'light', applications: 'light'}}))` or in Configure Settings → Core.
