# v0.64.0 live-test plan: creation wizard, creation record, advancement log, Spend Karma, approval queue

Two tabs: **GM** (GM AI) and **PL** (ZZ Testplayer). Drive the UI with JavaScript in the page and read the DOM; the pane is narrow, so prefer `element.querySelector(...)` checks over screenshots. After a click or a field change, wait about 500 ms before reading (the wizard and Spend Karma re-render 200 ms after an update; the advancement log writes a burst 700 ms after the last change, on the client that made the change; `await game.sr2e.api.flushAdvancement()` in that tab writes it at once).

Each check: **steps** → *expected*. Write down anything that differs, plus the console errors seen during the check.

## How to drive it

- Character sheet actions: `sheet.element.querySelector('[data-action="spendKarma"]').click()`. Tabs: `[data-action="tab"][data-tab="current"]` (and `creation`, `main`, `upkeep`, `bio`). Edit/Play: `[data-action="sheetMode"]`.
- Wizard: `const w = await game.sr2e.api.creationWizard(actor); const W = () => w.element;`. Steps `[data-action="wizStep"][data-step="skills"]`, `wizNext`, `wizBack`, `wizFinish`. Fields have `data-wiz`: set the value (radios: `checked = true`), then `el.dispatchEvent(new Event('change'))`.
- Spend Karma: `const s = game.sr2e.api.spendKarma(actor)`. Buttons: `spendRaise` (`data-attribute`, or `data-item-id` plus `data-part="spec"|"conc"`), `spendSpell`, `spendNewSkill`, `spendNewSpell`, `spendInitiate`, `spendEdge`, `spendBuyOff`, `cancelRequest`.
- Confirm dialogs (DialogV2): the newest `.application.dialog`, then `button[data-action="yes"]` or `[data-action="no"]`. Skill picker: form fields `kind`, `name`, `attribute`, `rating`, `spec`, `specRating`, `pay`, then `button[data-action="add"]`. Its live cost line is `[data-skill-cost]`.
- Add window: rows `tr[data-key]`, `.sr2e-add-tick`, `.sr2e-add-amount`, `.sr2e-add-payment`, `.sr2e-add-total`, `[data-action="addSelected"]`, notes `.sr2e-add-note`.
- GM panel: `game.sr2e.api.gmPanel()`, then `[data-action="gmTab"][data-tab="requests"]`, badge `.sr2e-badge`, rows `ul.sr2e-requests li`, `[data-action="approveRequest"]` / `[data-action="declineRequest"]` (with `data-uuid` and `data-id`).
- Flags: `actor.flags.sr2e.creation` (record, `v: 1`), `.creationDraft`, `.advancement` (log lines `{what, karma, nuyen, by, approvedBy, kind}`), `.requests`, `.build` (priorities).
