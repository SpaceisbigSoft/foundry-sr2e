**Dice.** In v14 `CONFIG.Dice.randomUniform = () => u` gives **inverted** faces: face = 6 − ⌊6u⌋. u 0.9 → 1, 0.7 → 2, 0.55 → 3, 0.4 → 4, 0.3 → 5. Never use u < 0.17 (a constant 6 explodes forever).
