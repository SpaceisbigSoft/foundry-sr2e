# v0.70.0 live-test plan: the v0.69.0 review's bugs and exploits (B1–B22)

Two tabs: **GM** (GM AI) and **PL** (ZZ Testplayer). Drive the UI with JavaScript in the page and read the DOM and documents; take the screenshots marked **[SHOT]**. After a click, an update or a new chat card, wait about 500 ms before reading (older cards are switched off 50 ms after a new card arrives; the area sweep runs 100 ms after a world-time or combat change). Every test document is named "ZZ …" (launched IC is named "<type>-<rating> (ZZ Host)"). A browser reload (F5) is enough after deploying: no new document types. After F5, log in again through /join, player tab first, then the GM tab.

Each check: **steps** → *expected*. Write down anything that differs, plus the console errors seen during the check. "Forced click" means: set `b.disabled = false` on the dead button, then `b.click()`. This tests the click-time guard, not only the greyed DOM.

The fixes are in section 1 of `docs/REVIEW-v0.69.md`. The new switches are `RULES.FIXES_V70` (`rules/config70.ts`) and the house-rule rows at the end of `HOUSE_RULES` (`settings.ts`).

## How to drive it

- **Cards.** `const last = (f = () => true) => game.messages.contents.filter(f).at(-1);` `const btns = (m, a) => [...document.querySelectorAll(`[data-message-id="${m.id}"] button[data-sr2e-action="${a}"]`)];`. A card normally shows twice (chat log and pop-up notification). Read both copies. The test snapshot is `m.getFlag('sr2e','test')`, with `testId` and `rerolls`. Karma re-roll button: `karmaReroll`; buy a success: `buySuccess`. Open the Chat sidebar tab in both tabs, because the Alt+D / Alt+R hotkeys only look in the rendered chat log.
- **Dead card text.** Replaced by a re-roll or a bought success: `p.sr2e-superseded` reads "Replaced: a Karma re-roll or a bought success made a newer card of this test; use that one." Replaced by the GM: "Replaced: the GM changed the target number (see the newer card)." A forced click on a dead card gives the same text as a warning.
- **Per-card marks.** On the message: flags `defended` and `resisted` (index lists), plus `knockdownRolled`, `scattered`, `cyberDamageRolled`, `toxinHitRolled` and `infectionRolled`. On the player's actor, when the player can't flag the message: `flags.sr2e.cardRolls`, with entries `<msgId>:defended:<i>`, `<msgId>:resisted:<i>` and `<msgId>:<key>`.
- **GM changes the TN:** `CONFIG.Actor.documentClass.retarget(msg, { baseTargetNumber: 3, modifiers: [] })`.
- **Dice:** `window.__zzRU ??= CONFIG.Dice.randomUniform;` then `CONFIG.Dice.randomUniform = () => 0.2` gives all 5s (hits), `() => 0.99` all 1s (a disaster) and `() => 0.5` all 3s. Restore with `CONFIG.Dice.randomUniform = __zzRU` in each tab. To get a hit on demand, add an attack modifier `{label: 'ZZ', value: -6}`.
- **House rules (GM):** `const HR = async (path, v) => { const c = game.settings.get('sr2e','houseRules'); const values = { ...c.values }; if (v === undefined) delete values[path]; else values[path] = v; await game.settings.set('sr2e','houseRules', { values, advanced: c.advanced ?? {} }); };` Read back with `game.sr2e.api.rules.FIXES_V70`. `HR(path)` with no value puts the default back. The window: `new (game.settings.menus.get('sr2e.houseRulesMenu').type)().render(true)`.
- **Timers:** if the user's **Gamemaster** account is online it is the active GM, and the world-time ticks, the area sweep, invisibility syncing, Apply (GM) auto-apply and the end-of-combat vehicle reset all run on *their* screen. Check `game.users.activeGM?.name` at the start and before checks 37–38, 53, 57–63 and 67–71. If it isn't GM AI, call the ticks directly with `CONFIG.Actor.documentClass.timedEffects({ worldTime: T, anyGm: true })` and `CONFIG.Actor.documentClass.securityResponses({ worldTime: T, anyGm: true })`. Mark the checks that need the active GM (37–38, 53, 68–69 and 71) "not run" unless GM AI is active.
- **World time:** save `window.__zzT = game.time.worldTime` once. Use `game.time.advance(s)` and put it back at clean-up (`game.time.advance(__zzT - game.time.worldTime)`).
- **Tokens:** the world is paused, so create tokens with `scene.createEmbeddedDocuments('Token', [(await a.getTokenDocument({x, y, actorLink: true})).toObject()])`. NPCs get unlinked tokens (no `actorLink`). To move a token, delete it and create it again.
- **Statuses:** `await a.toggleStatusEffect('paralysis', {active: true})`. The ids used here are `paralysis`, `sleep`, `sr2ePetrified`, `restrain` and `invisible`. Check each one exists first with `CONFIG.statusEffects.find(s => s.id === id)`.
- **Sheet actions:** `game.sr2e.runSheetAction(actor, 'attackWeapon', { itemId })`. Newest dialog: `[...document.querySelectorAll('.application.dialog')].at(-1)`. Close any leftover `DialogV2` before a dialog-driven check.
