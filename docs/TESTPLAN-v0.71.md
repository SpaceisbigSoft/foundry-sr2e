# v0.71.0 live-test plan: the v0.69.0 review's common rules holes (R1–R21)

Two tabs: **GM** (GM AI) and **PL** (ZZ Testplayer). Drive the UI with JavaScript in the page and read the DOM and documents; take the screenshots marked **[SHOT]**. After a click, an update or a new chat card, wait about 500 ms before reading (older cards are switched off 50 ms after a new card arrives). Every test document is named "ZZ …". A browser reload (F5) is enough after deploying: there are no new document types. After F5, log in again through /join, player tab first, then the GM tab.

Each check: **steps** → *expected*. Write down anything that differs, plus the console errors seen during the check. "Forced click" means: set `b.disabled = false` on the dead button, then `b.click()`. This tests the click-time guard, not only the greyed DOM.

The changes are in section 2 of `docs/REVIEW-v0.69.md` (R1–R21), plus the code-review fixes F1–F13 (marked "v0.71.0 review (F…)" in the source). The switches are `RULES.FIXES_V71` (`rules/config71.ts`) and the house-rule rows at the end of `HOUSE_RULES` (`settings.ts`). R4 (Athletics) and R14 (the your-turn helper) are plain fixes; R17 turns `RIGGING.needsAdaptation` on.

## How to drive it

- **Cards.** `const last = (f = () => true) => game.messages.contents.filter(f).at(-1);` `const btns = (m, sel) => [...document.querySelectorAll(`[data-message-id="${m.id}"] ${sel}`)];`. A card normally shows twice (chat log and pop-up). Read both copies. Contest and street cards carry `m.getFlag('sr2e','contest')` (`kind`, `id`, `sides[i].result`, `rerolls`, `bought`, `avoided`) and, where it applies, `buy`, `sell` and `haggled`. Their Karma buttons: `button[data-sr2e-action="contestKarma"][data-side="<i>"][data-op="reroll|avoid|buy"]`. Call the same path from code with `CONFIG.Actor.documentClass.contestKarma(msg, side, op)`.
- **Dead card text.** A contest card replaced by a Karma card: `p.sr2e-superseded` with the "newer card" text, as for tests in v0.70.0.
- **Dice:** `window.__zzRU ??= CONFIG.Dice.randomUniform;` then `CONFIG.Dice.randomUniform = () => 0.2` gives all 5s, `() => 0.99` all 1s and `() => 0.5` all 3s. Dice are rolled in the tab that runs the call, so rig the tab that acts. Restore with `CONFIG.Dice.randomUniform = __zzRU`. A mixed roll ("some hits, some failures"): `let k = 0; CONFIG.Dice.randomUniform = () => (k++ % 2 ? 0.5 : 0.2);`.
- **House rules (GM):** `const HR = async (path, v) => { const c = game.settings.get('sr2e','houseRules'); const values = { ...c.values }; if (v === undefined) delete values[path]; else values[path] = v; await game.settings.set('sr2e','houseRules', { values, advanced: c.advanced ?? {} }); };` Read back with `game.sr2e.api.rules.FIXES_V71`. `HR(path)` with no value puts the default back. The window: `new (game.settings.menus.get('sr2e.houseRulesMenu').type)().render(true)`.
- **Actions in combat:** `HR('ACTIONS.enforce', 'block')` for the checks that say so. Read the actions used with `actor.actionsUsed()` (simple-action units; 2 per phase). The combat must be started and the actor acting (`game.combat.combatant.actor`). Use `game.combat.nextTurn()` to move on.
- **Active GM:** world-time ticks and the hold-release hooks (`updateActor`, `deleteCombat`) run on the **active GM's** screen. Check `game.users.activeGM?.name` at the start and before checks 25–26. If it isn't GM AI, call `CONFIG.Actor.documentClass.releaseHolds({...})` by hand and mark the hook part "not run".
- **World time:** save `window.__zzT = game.time.worldTime` once and put it back at clean-up.
- **Tokens:** the world is paused, so create tokens with `scene.createEmbeddedDocuments('Token', [(await a.getTokenDocument({x, y, actorLink: true})).toObject()])`. NPCs get unlinked tokens (no `actorLink`); use the token actor's uuid (`canvas.tokens.placeables.find(t => t.name === 'ZZ Ganger').actor.uuid`) as their uuid.
- **Sheet actions:** `game.sr2e.runSheetAction(actor, action, { itemId })`. Newest dialog: `const dlg = () => [...document.querySelectorAll('.application.dialog')].at(-1);`. Close any leftover `DialogV2` before a dialog-driven check.
- **Projects** (things that take time): `actor.projects()`; GM finishes one at once with `actor.finishProject(id)`; giving up is `actor.cancelProject(id)`.
