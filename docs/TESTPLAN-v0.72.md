# v0.72.0 live-test plan: the v0.69.0 review's occasional and rare items (O1–O21)

Two tabs: **GM** (GM AI) and **PL** (ZZ Testplayer). Drive the UI with JavaScript in the page and read the DOM and documents; take the screenshots marked **[SHOT]**. After a click, an update or a new chat card, wait about 500 ms before reading (older cards are switched off 50 ms after a new card arrives). Every test document is named "ZZ …". A browser reload (F5) is enough after deploying: there are no new document types, only new schema fields (weapon `indirect`, spell `barrier` and `innate`, drug entry `doses`, anchored entry `karma`, the `physical barrier` kind and four bioware kinds) and two weapon/gear `ammoType` fields that lost their fixed choices. After F5, log in again through /join, player tab first, then the GM tab.

Each check: **steps** → *expected*. Write down anything that differs, plus the console errors seen during the check. "Forced click" means: set `b.disabled = false` on the dead button, then `b.click()`. "Record" means: the code's behaviour is not obviously right; write down what happens.

The changes are in section 3 of `docs/REVIEW-v0.69.md` (O1–O21). The switches are `RULES.COMBAT_V72` (`rules/config72/combat.ts`, O1–O7), `RULES.HEALTH_V72` (`rules/config72/health.ts`, O8–O12) and `RULES.MAGIC_V72` (`rules/config72/magic.ts`, O13–O21), with 59 house-rule rows at the end of `HOUSE_RULES` (`settings.ts`). The pure logic is in `rules/fieldsfire.ts`, `rules/vitals.ts` and `rules/sorcery.ts`.

## How to drive it

- **Cards.** `const last = (f = () => true) => game.messages.contents.filter(f).at(-1);` `const btns = (m, sel) => [...document.querySelectorAll(`[data-message-id="${m.id}"] ${sel}`)];`. A card normally shows twice (chat log and pop-up). Read both copies. The test snapshot is `m.getFlag('sr2e','test')` (its `modifiers`, `dice`, `poolDice`, `successes`, and for blasts the blast context). Karma re-roll button: `button[data-sr2e-action="karmaReroll"]`; Detonate: `blastScatter`; Resist: `resist` (damage) and `resistToxin` (toxins); GM apply card: `applyActorUpdate`; barrier spell cards: `createSpirit` and `placeWard`.
- **Dice:** `window.__zzRU ??= CONFIG.Dice.randomUniform;` then `CONFIG.Dice.randomUniform = () => 0.2` gives all 5s, `() => 0.99` all 1s and `() => 0.5` all 3s. Dice are rolled in the tab that runs the call, so rig the tab that acts. Restore with `CONFIG.Dice.randomUniform = __zzRU`. To land a blast on its aim point: roll the attack with 0.2 (many successes), then set 0.99 before pressing Detonate (scatter dice all 1s, cancelled by the successes: "It lands on target"). To get a hit on demand, add an attack modifier `{label: 'ZZ', value: -6}`.
- **House rules (GM):** `const HR = async (path, v) => { const c = game.settings.get('sr2e','houseRules'); const values = { ...c.values }; if (v === undefined) delete values[path]; else values[path] = v; await game.settings.set('sr2e','houseRules', { values, advanced: c.advanced ?? {} }); };` and for the Advanced JSON (arrays, per-kind objects): `const HRA = async (path, v) => { const c = game.settings.get('sr2e','houseRules'); const advanced = { ...(c.advanced ?? {}) }; if (v === undefined) delete advanced[path]; else advanced[path] = v; await game.settings.set('sr2e','houseRules', { values: c.values ?? {}, advanced }); };`. Read back with `game.sr2e.api.rules.COMBAT_V72` (or `HEALTH_V72`, `MAGIC_V72`). `HR(path)` / `HRA(path)` with no value puts the default back. The window: `new (game.settings.menus.get('sr2e.houseRulesMenu').type)().render(true)`. **Put each switch back at the end of its check** unless the check says otherwise.
- **Edges and flaws** (O11) need `STREET.qualities.enabled`: `HR('STREET.qualities.enabled', true)` for section L only.
- **Active GM:** world-time ticks (drug wear-off and crash) run on the active GM's screen. Check `game.users.activeGM?.name` at the start and before check 34. If it isn't GM AI, call `CONFIG.Actor.documentClass.timedEffects({ worldTime: game.time.worldTime, anyGm: true })` by hand and mark the hook part "not run".
- **World time:** save `window.__zzT = game.time.worldTime` once and put it back at clean-up.
- **Tokens:** the world is paused, so create tokens with `scene.createEmbeddedDocuments('Token', [(await a.getTokenDocument({x, y, actorLink: true})).toObject()])` (x, y = the top-left corner: centre − 50 for a 1 m token). NPCs get unlinked tokens (no `actorLink`); use the token actor's uuid (`canvas.tokens.placeables.find(t => t.name === 'ZZ Ganger').actor.uuid`). To move a token for a test that doesn't watch movement, delete it and create it again. **Section T (wards) needs real moves:** GM `game.togglePause(false, {broadcast: true})` before it and `game.togglePause(true, {broadcast: true})` after; a move is `tokenDoc.update({x, y})`.
- **Sheet actions:** `game.sr2e.runSheetAction(actor, action, { itemId })` (actions used: `attackWeapon`, `takeAim`, `takeDrug`, `hazard`, `castSpell`, `dropSustained`, `dispel`, `advanceInitiation`, `astralAttack`, `rejectionTest`). Newest dialog: `const dlg = () => [...document.querySelectorAll('.application.dialog')].at(-1);`. Close any leftover `DialogV2` before a dialog-driven check.
- **Approval queue:** `game.settings.set('sr2e','approvalQueue', true)` (GM) for section V; the GM approves in the GM panel → Requests (`game.sr2e.api.pendingRequests()` lists them).
